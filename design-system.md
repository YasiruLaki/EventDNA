# EventDNA Design System

> **Version:** 1.0\
> **Theme:** Premium Light UI\
> **Design Inspiration:** Luma, Linear, Notion Calendar, Raycast, Stripe
> Dashboard\
> **Font Family:** Inter

------------------------------------------------------------------------

# Design Principles

-   Minimal before decorative
-   Spacious layouts
-   Soft elevation instead of heavy shadows
-   Rounded geometry
-   High readability
-   Motion with purpose
-   Consistent spacing
-   White-first interface with purple accents

------------------------------------------------------------------------
